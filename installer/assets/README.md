# Installer assets

Placeholder for platform icons referenced by the generated `.desktop` file, the Windows
Scheduled Task shortcut, and a future macOS `.icns`/`.pkg` background image. None currently
exist — every generated artifact falls back to a generic system icon (`utilities-terminal` on
Linux) until real artwork is added here.

Expected files once available:
- `icon.ico` — Windows
- `icon.icns` — macOS
- `icon-256.png` / `icon.svg` — Linux `.desktop` entry and AppImage
